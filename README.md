# Como contribuir

Sugestões e contribuições são bem-vindas. A maior parte delas exige concordância com um acordo de licença de contribuição, no qual você declara ter o direito de ceder o uso do que está enviando. Os detalhes ficam no site do acordo.

Ao abrir uma solicitação de merge, um robô verifica automaticamente se o acordo é necessário e marca a solicitação de acordo com isso — rótulo e comentário. Basta seguir as instruções que ele deixa. Isso é feito uma única vez por conta, valendo para todos os repositórios que usam o mesmo acordo.

O projeto adota o código de conduta de código aberto da empresa. Dúvidas e comentários podem ser enviados ao endereço de contato indicado na documentação do código de conduta.
